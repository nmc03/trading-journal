# Contributing

This repository is published as an as-is personal project and is not actively maintained, but focused pull requests are welcome.

Before opening a pull request:

1. Keep changes scoped to the trading journal.
2. Do not commit credentials, .env files, SQLite databases or real trading data.
3. Run npm test in backend/.
4. Run npm run build in frontend/.
5. If Docker-related files change, run docker compose config and build the affected images.

For security issues, follow SECURITY.md instead of publishing exploit details in a normal issue.
