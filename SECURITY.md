# Security policy

Trading Journal is a small, single-user self-hosted project published as-is and is not actively maintained.

Do not include credentials, private trading data or working exploit details in a public issue.

If GitHub private vulnerability reporting is available for this repository, use it for security reports. Otherwise, open a minimal issue requesting a private contact channel without including sensitive exploit details.

Users are responsible for protecting backend/.env, the data/ directory and any reverse proxy used to expose the application.
